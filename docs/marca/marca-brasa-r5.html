A Brasa sem cara de restaurante japonês. As letras continuam escritas à mão, com menos contraste de pincel. Quem muda é a moldura: sai o anel de pincel aberto e entra uma forma precisa, várias delas tiradas do mundo dos gráficos.

Antes: Brasa

O anel de pincel aberto é o ensō, o círculo zen japonês. Somado ao contraste forte de pincel nas letras, puxa para restaurante japonês.

Hugo Nazário
Análise de dados
01

Medidor

O anel vira um arco fino de medidor, com a cor apagando ao longo da volta. A brasa continua, mas agora lembra um gráfico, não um pincel.

Hugo Nazário
Análise de dados
02

Régua

O anel vira um mostrador de marcações, como o eixo de um gráfico ou um instrumento de precisão. A mão fica só nas letras.

Hugo Nazário
Análise de dados
03

Anel fino

Círculo fechado de traço fino com o degradê. O mais limpo; a mão das letras contrasta com a geometria.

Hugo Nazário
Análise de dados
04

Moldura

Quadrado de cantos vivos no lugar do círculo. Some qualquer leitura oriental e fica mais editorial.

Hugo Nazário
Análise de dados
05

Eixo

Sem moldura: o HN maior apoiado numa linha de base, como o eixo de um gráfico, com a diagonal atravessando a linha.
